🩺 **Disease Prediction from Medical Data**

An interactive machine learning-powered web application built with Streamlit to predict the risk of diseases (such as diabetes) based on patient structured clinical parameters.
✨ **Key Features**

**Interactive User Input Sliders:**
Dynamically adjust clinical parameters such as Glucose Level, BMI, Blood Pressure, Insulin, Age, and more in real-time.

**Live Patient Parameter Summary:** 
Automatically aggregates and displays all entered patient metrics in a clean tabular summary before making a prediction.

**Instant Risk Assessment:**
Instantly evaluates health risk probabilities with a single click of the "Predict Disease Risk" button.

**Clean & Responsive UI:**
Designed with a modern, dark-themed layout tailored for ease of use and accessibility.

🛠️ **Tech Stack**

**Frontend & Web Framework:**
**Streamlit**

**Machine Learning & Data Processing:**

**Python, Scikit-Learn / PyTorch (depending on your model backend), Pandas, NumPy**

**Deployment:**
**Streamlit Cloud**
